# Research index

External sources and job-market context only. Research is not a source of candidate facts and
does not auto-load; reuse it only when its scope and freshness fit the current application.

## Company dossiers

| File | Scope |
|---|---|
| [`companies/Fello.md`](companies/Fello.md) | Fello company and role context |
| [`companies/LexsiLabs.md`](companies/LexsiLabs.md) | Platform, open-source stack, and company context |
| [`companies/Myntra.md`](companies/Myntra.md) | Company and role context |
| [`companies/Noise.md`](companies/Noise.md) | Products, direction, technical signals, and candidate match; reuse only within the documented 60-day window |
| [`companies/_template.md`](companies/_template.md) | Required dossier structure, source, date, and confidence fields |

Check each dossier's own source dates before reuse. If it does not state freshness clearly,
re-research instead of assuming it is current.
