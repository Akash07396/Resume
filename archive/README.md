# Archive catalog

This directory preserves superseded drafts, research copies, historical runs, and retired
templates. Its contents are not current instructions or candidate-truth owners. The active
system is mapped in the root `README.md` and specified in `SPEC.md`.

| Path | Contents | Use when |
|---|---|---|
| [`cleanup-20261008/`](cleanup-20261008/) | Stray template assets from the October cleanup | Reviewing that cleanup's preserved files |
| [`grilling/`](grilling/) | A historical planning session | Reconstructing that session only |
| [`pipeline_old/`](pipeline_old/) | Superseded pipeline specifications and prompts | Understanding earlier pipeline decisions |
| [`refactor-20261008/`](refactor-20261008/) | Refactor notes, old pipeline, handoffs, and legacy runs | Recovering October refactor context |
| [`rendercv-starter-20261016/`](rendercv-starter-20261016/) | Unmodified third-party starter snapshot and license | Checking upstream starter provenance |
| [`retired-docs-20261016/`](retired-docs-20261016/) | Retired role-research PDF, maintenance notes, and application prompt | Recovering the original documents after cleanup |
| [`templates-v1-dash-titles-20260915/`](templates-v1-dash-titles-20260915/) | Earlier template iteration and previews | Comparing historical visual iterations |
| [`templates-v3-retired-20261016/`](templates-v3-retired-20261016/) | Retired v3 template snapshot, fonts, and license | Tracing the approved Lato template history |

Root-level research and resume drafts are preserved as historical references. Start with
[`sources.md`](sources.md), [`resume_versions_handoff.md`](resume_versions_handoff.md), or
[`GITHUB_RESEARCH_REPORT_SOHAM_DATTA.md`](GITHUB_RESEARCH_REPORT_SOHAM_DATTA.md) only when the
task specifically needs their context. Do not use archived resume claims without rechecking
their active truth owner.
